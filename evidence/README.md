# Evidence

Proof for the numbers in `spec/facts.yaml`. One folder per fact item, named like the item: `evidence/endstop_board/`, `evidence/lens/`, `evidence/printer_fit/`.

What to put in:
- **measured:** a photo of the part with the caliper or a ruler in view, one per measured size if you can. Name files after the value, like `hole_spacing.jpg`.
- **datasheet:** the PDF, or a screenshot of the drawing if the PDF is huge. Put the link in the `evidence` field too.
- **fit coupon:** a photo of each test fit (rod in bore, insert in hole) plus a line in a `notes.md`: which size fit.

Keep photos under 2 MB each; phone photos resized to about 1600 px wide are fine.
